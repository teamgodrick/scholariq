ScholarIQ — Privacy-First Student Life & Academic OS

PROBLEM:
Engineering students in India balance 8-10 fragmented tools (WhatsApp groups, PDF syllabi, image timetables, calendars, GitHub repos, and fitness trackers). Cloud AI assistants store private syllabus and study materials on remote servers while lacking any context about the student's personal curriculum and academic deadlines.

SOLUTION:
ScholarIQ is a local-first, privacy-guaranteed Student Operating System that runs directly on the student's laptop with 0 cloud dependencies, zero subscription costs, and an explainable, empathetic intelligence layer powered by local LLMs (Meta Llama 3.2 8B + nomic-embed-text via LM Studio).

CORE MODULES IMPLEMENTED:
1. Prof. Pilot (Local Ground-Truth RAG Assistant):
   - Indexes syllabus and lecture PDFs into an on-device vector database using nomic-embed-text.
   - Answers questions strictly using verified text with precise page citations (e.g., DBMS_Unit1.pdf, p.4).
   - Generates active-recall Spaced Repetition Flashcards, multi-mark Exam Quizzes, Rapid Summaries, and simulates rigorous college Viva Voce oral exams.
   - Includes Web Speech voice input for hands-free query asking.

2. Chrono-Regulator (Dynamic Priority & Timetable Engine):
   - Extracts deadlines, subjects, and urgency from messy pasted WhatsApp announcements using Llama 3.2.
   - Calculates a weighted priority matrix (Exams > Labs > Assignments > Projects).
   - Automatically re-plans overdue or missed tasks.
   - Tracks weekly class timetable and detects room/time clashes.

3. GitHub Repo Sentinel (Project & Hackathon Anti-Stagnation):
   - Monitors student GitHub repository commit velocity.
   - Triggers an anti-stagnation radar alert when a project deadline is near (<= 4 days) and commits have stalled (>= 48 hours).
   - Tracks daily commit streaks and commits pushed today.

4. Wellness Core & Focus:
   - 30-second daily vital check-in covering 6 key student dimensions: Sleep (h), Mood (1-5), Water (glasses), Proper Meals (0-4), Exercise (min), and Screen Time (h).
   - Computes an explainable 0-100 Burnout Score combining physiological deficits and imminent academic workload.
   - Automatically adapts Today's Plan: when burnout is high, it shrinks the task schedule to the top 2 priorities and defers the rest.
   - Integrated Pomodoro focus timer with 20-20-20 eye break and posture prompts, plus Tele-MANAS national helpline information.

5. Academic Toolkit & Habit Coach:
   - 75% Attendance & Safe-to-Skip Rule Calculator: computes whether a student can safely bunk classes or how many consecutive classes are needed to restore the 75% minimum threshold.
   - Exam Mode Revision Planner: creates day-by-day milestone roadmaps before semester exams.
   - Compounding Habit Streaks (LeetCode, Git commits, reading).
   - Hostel Budget Manager: calculates remaining balance and safe daily spending limit for the month.

TECH STACK:
- Frontend: React 19, Vite, Cosmic Purple Theme with glassmorphism, micro-interactions, and Web Speech API.
- Backend: FastAPI, Uvicorn, Python, NumPy cosine vector matching, PyPDF text extractor.
- Local AI Engine: LM Studio OpenAI-compatible local server (Port 1234), Meta Llama 3.2 8B Instruct, nomic-embed-text.
- Database: SQLite with automatic migrations (100% on-device).

PRIVACY & COST GUARANTEE:
Zero personal data, PDFs, messages, or attendance logs leave the student's laptop. Cloud API cost is exactly ₹0.
